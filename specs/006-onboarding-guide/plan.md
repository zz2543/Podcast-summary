# 006 — 首次打开的 API 填写引导（macOS）

**日期**：2026-09-25
**要什么**：第一次打开 Podsum 时，在**真实的设置界面上**一步一步带着填 API——
不是一页文字说明，而是浮在界面上的实时引导：当前要填的那一格被高亮、周围压暗，
旁边一个气泡讲清楚这一格填什么、去哪儿拿、长什么样；填上的一瞬间气泡里的状态变成 ✓。

## 形态

- **聚光灯 + 气泡**，画在「设置 › 接口」这一页的真实表单上面。
  - 压暗层与高亮框都不拦点击（`allowsHitTesting(false)`），用户直接在高亮的输入框里打字；
    只有气泡本身可点。
  - 气泡跟着目标走：目标在下半屏就放上面，反之放下面；目标不在视野里先滚过去。
  - 欢迎页和收尾页没有目标，气泡居中、整窗压暗。
- **实时**：每一步有一个「完成条件」（字段非空、测试连接通过、后端就绪），
  气泡底部的状态行跟着设置实时变化：`等你填写…` → `✓ 已填好`。未完成时「下一步」变成「先跳过」。
- **按所选供应商生成步骤**：换了供应商，后面的步骤随之换成那一家的字段，不会指着一个不存在的输入框。
- **每一格讲到能照着做**：去哪个控制台（带「打开页面」按钮）、控制台里点哪几下、
  值长什么样（`sk-` 开头 / 一串数字）、常见坑（Secret 只显示一次、要开通哪两项服务）。
  能给默认值的给「一键填入」（接口地址、模型名的常见组合）。

## 步骤（以默认组合为例）

1. 欢迎：要准备什么（摘要用的 LLM + 转写用的 ASR，音频摘要可选）、钱怎么花（按用量，付给你自己选的厂商）、
   key 存钥匙串。给两条路：「最省事：一个阿里云百炼 key 管摘要和转写」「默认：DeepSeek + 豆包」，点了就把供应商设好。
2. LLM 供应商 → 3. 接口地址（一键填入 DeepSeek / OpenAI / 百炼兼容模式）→ 4. 模型名 → 5. API Key → 6. 测试连接（通过才算完成）
7. 转写供应商 → 8… 该供应商的每一个字段（豆包是 AK、SK、App ID、Token 四格）
9. 音频摘要开关（建议先关）→ 开着则继续带填该供应商字段
10. 应用并重启后端（后端就绪才算完成，失败时气泡里直接显示原因）
11. 收尾：⌘N 添加剧集、快捷提交、视频下载失败去哪儿更新解析组件

## 第二层：带着去厂商网站（2026-09-25 追加）

设置页上的气泡只能讲到"去哪儿拿"。拿 key 的那几步发生在厂商网站上，是新用户最容易卡住的地方，
所以要**直接把网站打开，并一步一步指着点哪、建什么、选什么**。

决定（用户选定）：

- **用系统浏览器打开**（用户现成的登录态），Podsum 在屏幕右侧放一个**置顶的悬浮面板**逐步指引。
  系统浏览器里的页面 Podsum 碰不到，所以网页上没有高亮——面板要把每一步写到"看见什么、点哪个、选什么"。
- **复制即填入**：引导进行到拿 key 的那一步时监听剪贴板；出现形如该 key 的内容，面板提示
  「检测到 sk-…abcd，填入 API Key？」，确认后写进钥匙串并勾掉这一步。只在这一步监听，不存不传。
- **先做三家**：DeepSeek（摘要）、火山引擎 / 豆包（转写，AK/SK + 旧版控制台建应用拿 APP ID / Token）、阿里云百炼（北京地域）。
- 面板上的点击路径按**登录后的真实页面**核对（用户登录，内置浏览器只读页面结构，不创建、不修改）。
  火山引擎的域名内置浏览器打不开，按官方文档（快速入门新/旧版控制台、控制台 FAQ、API 密钥文档）写。

形态：设置页气泡里拿 key 的那一步多一个主按钮「带我去创建」→ 默认浏览器打开对应页面 + 弹出悬浮面板；
面板上：厂商名、分步清单（当前步放大、已完成打勾）、每步的「打开这一页」、剪贴板检测条、「回到 Podsum」。

## 入口

- 首次启动且还没配置：主窗口自动打开设置并开始引导（只自动一次，记在 UserDefaults）。
- 主窗口「先填你自己的 API」卡片上的主按钮改为「开始引导」。
- 「设置 › 通用」里的「重新开始新手引导」。

## 实现

| 文件 | 内容 |
|---|---|
| `Data/OnboardingGuide.swift` | 引导状态（是否进行中、第几步、设置窗口当前页、测试连接是否通过、目标位置）与步骤生成 |
| `Views/OnboardingOverlay.swift` | 压暗 + 高亮 + 气泡；`onboardingTarget(_:)` 修饰符让表单行上报自己的位置 |
| `Views/SettingsView.swift` | TabView 可被引导切页；各输入行挂上目标；测试连接结果回报给引导 |
| `Views/RootView.swift`、`PodsumApp.swift` | 入口与注入 |

**目标位置怎么拿**：输入行用背景里的 `GeometryReader` 上报自己在**窗口坐标**（`.global`）里的框，
覆盖层再换算回自己的坐标。不用 `anchorPreference`——grouped Form 在 macOS 上可能由表格承载，
偏好值未必能穿过行宿主传上来；窗口坐标则不受这个影响，滚动时也会随之刷新。

## 验证

用改了 bundle id 的验证副本（存储隔离，天然就是"第一次打开、什么都没填"的状态），
在后台用 computer-use 截图逐步看气泡位置与内容、点「下一步」、往普通输入框里打字看状态行实时变化。
密码框在后台模式下不能输入，那几步只看呈现。

## 验证记录（2026-09-25）

验证副本：Debug 构建改 bundle id 为 `local.podsum.macclient.onboard`（全新身份 = 第一次打开），后台 computer-use 操作。
Debug 专用开关：`PODSUM_DEBUG_PASTEBOARD` 换成私有具名剪贴板（测试写假 key，不碰系统剪贴板）、
`PODSUM_DEBUG_NO_BROWSER` 不真的打开浏览器。

| 项 | 结果 |
|---|---|
| 首次启动自动打开设置、切到「接口」、窗口加大到 620 宽 | 通过 |
| 欢迎页、供应商页气泡与高亮框位置；换步动画 | 通过 |
| 点「DeepSeek」一键填入 → 输入框即时有值、状态行变「✓ 已填好」、按钮由「先跳过」变强调色「下一步」、底部「还缺」同步减少 | 通过 |
| 模型步按接口地址推荐 `deepseek-flash` / `deepseek-v4-pro` | 通过 |
| API Key 步出现「带我去网站创建」→ 屏幕右侧弹出悬浮面板（不抢焦点），4 步清单 | 通过 |
| 面板走到「复制」步 → 往测试剪贴板写 `sk-…` 假 key → 1.5 秒内出现「检测到你刚复制的 LLM API Key · sk-po…abcd」 | 通过 |
| 点「填入 Podsum」→ 面板 4 步全勾、出现「回到 Podsum 继续」；设置页 API Key 框有值、气泡「✓ 已填好」、「带我去网站创建」自动隐藏 | 通过 |

**踩到并修掉的**

- 测试副本被拉到前台时，用户正在打字的空格 / 回车落进了设置窗口，把引导一格格往前推（一次跳到第 9 步）。
  真实使用中用户是自己打开的 app，不会发生"抢焦点"，但点完「下一步」后焦点留在按钮上、之后输入法选词的空格
  照样会推它——所以气泡与面板里的按钮一律 `.focusable(false)`，主按钮改用自定义样式（不当窗口默认按钮、不接回车）。
- 深色模式下 42% 的压暗几乎看不出来，改为深色 62% / 浅色 38%。
- 接口地址的占位符写成 URL 会被渲染成链接蓝，像是"已经填好了"，改为「厂商文档里的 base_url」。
- 填好之后面板仍显示「正在等你点复制」，改为已有值就不再显示。

**没验到的**

- 火山引擎两段网站引导（账号密钥、豆包应用）只核对了呈现逻辑与文档，内置浏览器打不开 volcengine.com，没对着真实页面看。
- 系统剪贴板的授权弹窗（macOS 读剪贴板时可能询问）没在真机上触发过——测试用的是私有剪贴板。
- 浅色外观、英文界面下的气泡排版。
